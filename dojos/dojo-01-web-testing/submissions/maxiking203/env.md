# Erstelle uv Projekt
```
# Projekt mit Python 3.13 initialisieren
uv init --app -p 3.13 # auch andere Python-Versionen möglich

# Python zu Version pinnen
uv python pin 3.13
```

# Robot Framework Pakete installieren
```
uv add robotframework
uv add robotframework-browser
```

# init rfbrowser
```
uv run -v rfbrowser init
```

# VS Code Einstellungen
- Python Interpreter auf uv env setzen
