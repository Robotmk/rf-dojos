1. install Python - https://www.python.org/downloads/
2. Install NodeJS - https://nodejs.org/en/download/  
3. Upgrade python - python.exe -m pip install --upgrade pip
4. Checks:
   - python --version --> Python 3.14.6
   - npn --version --> 11.10.1
   - node --version --> v24.15.0

4. Create requirements.txt 
   - robotframework>=7.0 
   - robotframework-seleniumlibrary>=6.7.0 
   - selenium>=4.20.0
   - webdriver-manager>=4.0.0 
   - robotframework-browser>=20.1.0
5. run pip install -r requirements.txt
6. Initialize Playright: rfbrowser init --> rfbrowser init completed
7. Test with a demo test
